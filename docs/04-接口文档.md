## 一、通用约定

**Base URL**：`http://127.0.0.1:8000/api/v1`

**统一响应结构**

```json
{ "code": 0, "message": "ok", "data": { }, "trace_id": "a1b2c3d4" }
```

- `code = 0` 表示成功，非 0 为业务错误码（见第四节）
- `trace_id` 与响应头 `X-Trace-Id`、服务端日志一一对应，便于排查

**鉴权**

- 登录后返回 JWT，后续请求带 `Authorization: Bearer <token>`
- 「鉴权」列取值：公开 / 需登录 / 需作者 / 需管理员

**分页**

列表接口统一接受 `page`（从 1 开始）与 `size`，返回 `{list, total, page, size, pages}`。

**限流与防爬**

| 分类 | 上限（每分钟/IP） |
|---|---|
| 认证接口 | 6 |
| 章节正文 | 30（另按账号 40） |
| 写操作 | 20 |
| 其他读接口 | 150 |

超限返回 `429` 并带 `Retry-After`；UA 命中脚本特征（curl / requests 等）且不含 `Mozilla` 时直接拒绝。

**可见性规则**

- 书籍：`audit_status=2 且 shelf_status=2` 才出现在前台
- 章节：`status=1 且 audit_status=2` 才可读，否则返回 `3002`
- 付费章节未购买：返回 `locked=true` 且正文为空，不报错

## 四、错误码

| code | HTTP | 含义 |
|---|---|---|
| 0 | 200 | 成功 |
| 1001 | 422 | 参数或业务规则不满足 |
| 1002 | 401 | 未登录 / Token 失效 |
| 1003 | 403 | 无权限 |
| 1004 | 404 | 资源不存在 |
| 1005 | 429 | 请求过于频繁 |
| 2001 | 400 | 注册参数错误 |
| 2002 | 400 | 用户名或密码错误 |
| 2003 | 403 | 账号被禁用 |
| 2004 | 400 | 旧密码错误 |
| 3001 | 404 | 书籍不存在或已下架 |
| 3002 | 404 | 章节不存在 |
| 3003 | 400 | 章节不属于该书籍 |
| 3004 | 402 | 付费内容未购买 |
| 4001 | 400 | 上传文件不合法 |
| 5001 | 400 | 评论/内容校验失败 |
| 5002 | 403 | 无权删除他人内容 |
| 6001 | 403 | 非本人作品 |
| 9001 | 500 | 业务异常 |
| 9999 | 500 | 未捕获异常 |
