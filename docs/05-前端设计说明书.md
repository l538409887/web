> 系统名称：基于 Python 的轻量化 Web 小说平台
> 版本：v1.0　编写日期：2026-11-26
> 对应论文章节：第 4 章「详细设计 · 前端部分」
> 参考站点：起点中文网、刺猬猫阅读、纵横中文网

## 1. 设计目标

| 目标 | 具体表现 |
|---|---|
| **以内容为中心** | 页面里书封与书名是视觉焦点，装饰性元素只做点缀 |
| **阅读零干扰** | 阅读页去掉一切与正文无关的元素，只留翻页与设置 |
| **信息密度高但不拥挤** | 列表用卡片网格，每屏 4~5 列；留白足够 |
| **一眼看懂** | 任何页面三层之内能回到「书」或「章」 |

### 1.1 与参考站的差异

| 参考站做法 | 本项目做法 | 原因 |
|---|---|---|
| 首页十几个运营位、活动 banner | 轮播 3 张 + 4 个榜单 + 2 个列表 | 运营位需要内容运营，毕设没有素材 |
| 顶部导航两行、几十个入口 | 一行导航 + 10 个分类 | 减少实现与维护成本 |
| 书籍详情页含月票、打赏、粉丝榜 | 详情页只保留简介、目录、书评 | 砍掉商业化模块 |
| 阅读页有章评浮层、段评 | 只做章评列表，放在正文下方 | 段评需要文本定位，复杂度高 |

### 2.2 字体

| 场景 | 字体栈 | 字号 |
|---|---|---|
| UI 正文 | `-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif` | 14px / 1.6 |
| 标题 | 同上，`font-weight: 600` | 20~28px |
| **阅读正文** | `"Noto Serif SC", "Source Han Serif SC", "Songti SC", 宋体, serif` | 16~22px（可调），行高 1.8~2.2 |
| 数字/热度 | `ui-monospace, Consolas, monospace` | 13px |

> 阅读页用**宋体**而非黑体，是中文长文阅读的传统选择：字形有粗细变化，长时间阅读眼部疲劳更低。

### 2.3 间距与栅格

- 基础单位 **8px**，所有 `padding` / `margin` 取 4 的倍数。
- 内容区最大宽度 **1200px**，居中，左右留白 24px。
- 书籍网格：`repeat(auto-fill, minmax(160px, 1fr))`，间距 20px。

| `/:pathMatch(.*)*` | `NotFound` | AppLayout | — |

**路由守卫逻辑**

```js
router.beforeEach(async (to) => {
  document.title = to.meta.title ? `${to.meta.title} · 轻量化小说平台` : '轻量化小说平台'

  const user = useUserStore()
  if (!user.initialized) await user.fetchMe()          // 刷新后恢复登录态

  if (to.meta.requiresAuth && !user.isLogin)
    return { path: '/login', query: { redirect: to.fullPath } }

  if (to.meta.roles && !to.meta.roles.includes(user.role))
    return { path: '/' }

  if (to.meta.guestOnly && user.isLogin)
    return { path: '/' }
})
```

> `guestOnly` 用于登录/注册页：已登录用户不应再看到这两个页面。

### 4.1 三种布局

| 布局 | 用于 | 结构 |

| `AppLayout` | 大部分页面 | `AppHeader` + `<router-view>` + `AppFooter` |

### 4.2 `AppHeader`（全局导航）

```
┌──────────────────────────────────────────────────────────────┐
```

| 区域 | 行为 |

#### 5.4.1 阅读设置（`readerStore`）

| 项 | 选项 | 实现 |
|---|---|---|
| 字号 | 16 / 18 / 20 / 22 px | `--reader-font-size` |
| 行距 | 1.8 / 2.0 / 2.2 | `--reader-line-height` |
| 背景 | 白 `#FFFFFF` / 米黄 `#F5EFE3` / 护眼绿 `#D8E6D5` / 夜间 `#1A1A1A` | `data-theme` 属性 |
| 字体 | 宋体 / 黑体 | `--reader-font-family` |

**持久化**：写入 `localStorage` 键 `novel_platform_reader_settings`，初始化时读取并应用到根节点 `style`。

```js
// stores/reader.js
const DEFAULTS = { fontSize: 18, lineHeight: 2.0, theme: 'white', font: 'serif' }
export const useReaderStore = defineStore('reader', () => {
  const settings = ref({ ...DEFAULTS, ...JSON.parse(localStorage.getItem('novel_platform_reader_settings') || '{}') })
  watch(settings, v => localStorage.setItem('novel_platform_reader_settings', JSON.stringify(v)), { deep: true })
  return { settings }
})
```

#### 5.4.2 交互细节

| 交互 | 行为 |
|---|---|
| 进入页面 | `scrollTo(0,0)`；请求章节；**3 秒后**上报进度 |
| 翻章 | 请求新章节 → 立即滚回顶部 → 上报进度 |
| 快捷键 | `←` 上一章、`→` 下一章、`Esc` 返回详情页 |
| 顶部条 | 向下滚动隐藏、向上滚动出现（`scroll` 节流 100ms） |
| 目录抽屉 | 点「目录」右侧滑出，高亮当前章，点击跳转并关闭 |
| 进度保存 | `progress = scrollY / (docHeight - winHeight) * 100`，取整 0~100 |
| 章节不存在 | 显示 `EmptyState` + 「返回书籍详情」按钮 |
| 键盘翻页 | 在输入框聚焦时禁用快捷键（`e.target.tagName === 'INPUT'` 时 return） |

> **为什么等 3 秒再上报**：用户可能误点进某一章立刻退出。3 秒是「确实在读」的经验阈值。

### 5.5 书架 `/shelf`

- 视图切换：**网格** / **列表**（列表显示「读到第 3 章 · 45%」）。
- 排序：置顶优先 → 收藏时间倒序。
- 卡片操作：`继续阅读`、`移出书架`（二次确认）、`置顶`。
- 有更新的书：书名右上角一个红点 + tooltip「有更新」。
- 空态：`EmptyState` + 「去书库看看」按钮。

### 5.6 排行榜 `/rank`

- 顶部 Tab：点击榜 / 收藏榜 / 推荐榜 / 新书榜。
- 列表项：`名次徽章 + 封面缩略图 + 书名 + 作者 + 分类 + 热度值`。
- 前三名徽章用金/银/铜色。
- 切换 Tab 用 `router.replace` 同步 `?type=`。

### 5.7 个人中心 `/user/*`

左侧二级菜单（资料 / 阅读记录 / 我的评论），右侧内容区。

- **资料**：头像、昵称、简介、邮箱（只读）、修改密码入口。
- **阅读记录**：`GET /history`，卡片形式，点击「继续阅读」。
- **我的评论**：评论列表 + 所属书籍 + 删除按钮。

### 5.8 登录 / 注册

- 居中卡片，背景可用首页封面做模糊底图（`backdrop-filter: blur(12px)`）。
- 表单校验：前端即时校验（长度、两次密码一致），提交后展示后端 `message`。
- 登录成功：`router.push(route.query.redirect || '/')`。
- 演示账号提示（仅开发环境显示）：

```
演示账号：reader1 / reader123　　管理员：admin / admin123
```

> 这行提示在答辩演示时非常有用，但生产环境要通过 `import.meta.env.DEV` 控制，不能出现在正式包里。

### 5.9 后台 `/admin`

- 左侧菜单 + 顶部面包屑。
- 列表页统一：搜索栏 + 表格 + 分页 + 操作列。
- 危险操作（删除、下架、禁用）一律二次确认（`ElMessageBox.confirm`）。
- 数据看板：4 个统计卡片 + 一张近 7 日新增趋势图（可用 ECharts，也可先用静态卡片，P4 再补图表）。

## 6. 状态管理

| Store | state | 说明 |
|---|---|---|
| `user` | `token`、`profile`、`role`、`initialized` | 登录态，`isLogin` 为 `computed` |
| `reader` | `settings` | 阅读设置，持久化到 localStorage |
| `app` | `loading`（全局）| 可选，用于顶部进度条 |

**刻意不放进 Pinia 的状态**：列表数据、分页参数、表单数据。它们只在单个页面内使用，用 `ref` 即可，塞进 store 反而增加心智负担。

## 8. 状态与反馈规范

| 状态 | 规范 |
|---|---|
| **加载中** | 列表用骨架屏（`PageSkeleton`），单按钮用 `loading` 属性，禁止整页 loading 遮罩 |
| **空数据** | `EmptyState` 组件：插图 + 一句说明 + 一个行动按钮（如「去书库看看」） |
| **请求失败** | toast 提示 + 页面保留已有内容，提供「重试」按钮 |
| **404** | 独立页面，提供「回首页」「去书库」两个出口 |
| **500** | 独立页面，提示「稍后再试」，**不展示堆栈** |
| **表单提交** | 按钮 `loading` + 禁用，防重复提交 |

## 9. 响应式

| 断点 | 布局 |
|---|---|
| ≥ 1200px | 内容区 1200px 居中；书籍网格 5 列 |
| 992 ~ 1199px | 内容区自适应；网格 4 列 |
| 768 ~ 991px | 网格 3 列；导航折叠为汉堡菜单 |
| < 768px | 网格 2 列；阅读页字号默认 18px、左右 padding 16px；表格类页面改为卡片列表 |

> 移动端不是重点（毕设演示在 PC），但**阅读页必须能在手机上看**，因为老师可能会用手机扫一眼。

## 10. 性能

| 措施 | 说明 |
|---|---|
| 路由懒加载 | `component: () => import('@/views/Reader.vue')` |
| 图片懒加载 | `loading="lazy"` + 封面统一 200×267 尺寸，避免 CLS |
| 无封面兜底 | `cover` 为空时渲染渐变占位（主色底 + 书名首字），不显示裂图 |
| 组件按需引入 | Element Plus 用 `unplugin-vue-components` 自动按需 |
| 请求去重 | 快速切换 Tab 时取消上一次未完成的请求（AbortController） |
| 构建产物 | `npm run build` 后 gzip，首屏 JS ≤ 500KB |
